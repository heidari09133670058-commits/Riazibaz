# ریاضی‌باز — اپلیکیشن آموزش ریاضی کودکان

اپلیکیشن نمونه اندرویدی فارسی برای کودکان ۴ تا ۷ سال، ساخته‌شده با Kotlin و Jetpack Compose.

## امکانات نسخه اولیه
- محیط فارسی و راست‌چین
- شمارش اعداد
- تمرین جمع و تفریق ساده
- آشنایی با شکل‌های هندسی
- امتیاز و ستاره برای پاسخ درست
- بدون تبلیغات، اینترنت یا ثبت‌نام

## باز کردن و اجرا
1. Android Studio را نصب کنید.
2. این پوشه را در Android Studio باز کنید.
3. اجازه دهید Gradle Sync کامل شود.
4. یک شبیه‌ساز یا گوشی اندرویدی متصل کنید.
5. دکمه Run را بزنید.

برای ساخت APK از منوی Build گزینه Build APK(s) را انتخاب کنید.

## نکته
این یک پروژه منبع قابل ویرایش و نسخه اولیه است، نه فایل APK از پیش کامپایل‌شده. برای انتشار عمومی، تست روی دستگاه‌های واقعی، بازبینی تجربه کاربری کودک و تکمیل دسترس‌پذیری توصیه می‌شود.


## کامپایل آنلاین با Codemagic
1. این پوشه را در یک مخزن GitHub بارگذاری کنید.
2. در https://codemagic.io/ وارد شوید و GitHub را متصل کنید.
3. مخزن RiaziBaz را اضافه کنید و workflow با نام `RiaziBaz Android APK` را انتخاب کنید.
4. Build را شروع کنید.
5. پس از پایان موفق، فایل APK را از بخش Artifacts دانلود کنید.

تنظیمات این پروژه در فایل `codemagic.yaml` قرار دارد. این workflow فایل APK آزمایشی (debug) تولید می‌کند؛ برای انتشار در Google Play باید نسخه release و امضای دیجیتال جداگانه تنظیم شود.
